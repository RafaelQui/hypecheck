## 3. Storage

Connect review media to the existing Supabase Storage buckets:

* review-videos
* review-images
* avatars

Storage paths MUST begin with the authenticated user's UUID because the existing RLS policies require that.

Examples:

review-videos/{user_id}/{unique_filename}.mp4

review-images/{user_id}/{unique_filename}.jpg

avatars/{user_id}/{unique_filename}.jpg

Do not use a service-role key to bypass Storage RLS.

## 4. Review media

When someone posts a video review:

1. Confirm they are authenticated.
2. Upload the video to `review-videos`.
3. Obtain the appropriate public URL/path.
4. Save it to the corresponding review's `video_url`.

For review photos:

1. Upload to `review-images`.
2. Save the resulting URL/path to `photo_url`.

## 5. Avatars

When a user changes their profile picture:

1. Upload the image to `avatars`.
2. Save the resulting URL/path to `profiles.avatar_url`.
